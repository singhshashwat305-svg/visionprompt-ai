# 🖼️ VisionPrompt AI

An AI-powered Image Analytics application built with **Streamlit** and **Google Gemini**.

Upload an image, ask questions in natural language, and receive AI-generated insights instantly.

---

## ✨ Features

- Upload JPG, JPEG, and PNG images
- AI-powered image analysis
- Ask custom questions about the uploaded image
- Google Gemini integration
- Secure API key using `.env`
- Clean Streamlit interface

---

## 🛠️ Tech Stack

- Python
- Streamlit
- Google Gemini API
- Pillow
- Python Dotenv

---

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/singhshashwat305-svg/visionprompt-ai.git
```

Move into the project

```bash
cd visionprompt-ai
```

Install dependencies

```bash
pip install -r requirements.txt
```

---

## ▶️ Run Locally

```bash
streamlit run app.py
```

---

## 🔑 Environment Variables

Create a `.env` file

```env
GEMINI_API_KEY=YOUR_API_KEY
```
